Co je to přístupnost webu

Bezbariérový web umožňuje návštěvníkům s postižením procházet web se stejnou nebo podobnou úrovní snadnosti a zábavy jako ostatní návštěvníci. Toho lze dosáhnout díky možnostem systému, na kterém web funguje, a prostřednictvím asistenčních technologií.
